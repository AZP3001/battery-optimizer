# battery-optimizer
A Universal Battery-Optimizer that utilizes ADB via USB-DEBUGGING to kill unneded background processes and freeing up memory to save battery and cpu Power.

This application Revokes permissions from selected apps (whitelist/blacklist) to run in background called "run-any-inbackground" and remove the ability to "wake up" the phone cpu for background running turns off background mobile date usage to keep it asleep even more and forces apps to deep sleep.
